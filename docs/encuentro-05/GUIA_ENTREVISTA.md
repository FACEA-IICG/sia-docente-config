# Guía breve de entrevista semiestructurada

Cada equipo realiza al menos ocho preguntas:

1. dos preguntas abiertas sobre objetivos y problemas;
2. dos preguntas sobre el proceso actual y sus participantes;
3. dos preguntas sobre excepciones, errores o casos difíciles;
4. una pregunta sobre datos, permisos o seguridad;
5. una pregunta sobre el criterio con que el actor consideraría exitosa la solución.

## Preguntas de profundización

- ¿Puede contar un ejemplo concreto?
- ¿Qué ocurre antes y después?
- ¿Quién participa o autoriza?
- ¿Qué información necesita y de dónde proviene?
- ¿Qué sucede cuando el proceso falla o cambia?
- ¿Cómo comprobaríamos que quedó correctamente resuelto?

No pregunte “¿quiere un botón para…?”. Primero investigue el problema, el proceso y la necesidad.
