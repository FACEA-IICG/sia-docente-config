# Encuentro 5 · Requisitos y entorno Docker–Django

Este material tiene dos propósitos:

1. practicar la identificación de requisitos mediante una entrevista simulada;
2. comprobar una aplicación mínima Django con PostgreSQL dentro de Docker.

## Productos del encuentro

- `docs/requisitos/entrevista-simulada-equipo-X.md`
- evidencia de `docker compose ps` y de `http://localhost:8000/health/`

La entrevista simulada prepara el guion del Encuentro 6. No reemplaza una entrevista real ni autoriza a inventar requisitos.
